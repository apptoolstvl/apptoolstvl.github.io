Import

Import, CSV & QR codes

Bring lists and libraries into ListHive from a .listhive file, add many items at once from a spreadsheet, and share a file with a QR code that others can scan.

On this page
  1. Import a .listhive file
  2. When names already exist
  3. Import items from a spreadsheet (CSV)
  4. Download a CSV template
  5. Scan a QR code
  6. Create a QR code

Import a .listhive file

There are two ways in:

  • Open the file from WhatsApp, Gmail, Files or Drive and choose ListHive. You'll be asked Import into ListHive?
  • Or go to Settings → Import and pick the file.

ListHive shows what's inside, for example 2 libraries, 12 items and a list, and whether it Includes media files. Tap Import. When it finishes, Import Complete lists what was created or merged.

Try it with the example files

Download Recipe-Box.listhive, then Birthday-Dinner.listhive, and open them on your phone. The second file also contains two recipes, so you'll see the conflict screen.

For a file in Google Drive or another cloud app, download it to your phone first if the import fails. ListHive also needs free space of about twice the file's size while importing.

When names already exist

If the file contains a library or list with the same name as one you already have, Import Conflicts asks what to do with each one.

For a library:

  • Merge (default): add only the items you don't already have, matched by primary field. Your existing items aren't changed.
  • Create New: import it as a separate library called e.g. Recipe Box (2).
  • Overwrite: replace your matching items with the file's version, and add any new ones.

For a list:

  • Add Groups: bring the file's groups into your list. A group with exactly the same name as one of yours is merged into it; other groups are added as new ones.
  • Create New: import it as a separate list.

Merge and Overwrite only fill fields your library already has. If the file's library has extra fields, choose Create New to keep them.

Import items from a spreadsheet (CSV)

Typing in fifty recipes one by one is no fun. If they're in a spreadsheet (Excel, Google Sheets, Numbers), save it as CSV and import it into a library.

The first row must be the column headings, and one column must be named exactly like the library's primary field (capitals don't matter). For the Recipe Box, that looks like this:

RecipeCuisineTime (min)DifficultyServesVegetarian
Mushroom RisottoItalian35Medium4yes
Chana MasalaIndian30Easy4yes
Shepherd's PieBritish75Medium6no

You can download this example as recipes-to-import.csv.

  1. Open the library and tap CSV.
  2. Under If a row's “Recipe” matches an existing item, choose what happens when a name already exists: Skip Item, Replace or Add as Duplicate.
  3. Tick Add new fields found in CSV if the spreadsheet has columns the library doesn't (like Vegetarian). Otherwise those columns are ignored.
  4. Tap Import from CSV and pick the file.

If there are new columns, New Fields Found shows each one with the type ListHive guessed from its values. Vegetarian holds yes and no, so it's detected as boolean. Tap a different type if the guess is wrong, then Add 1 Field & Import.

ListHive guesses yes/no, numbers, dates, photos, videos, audio, links, emails, phone numbers and multi-line text. It never guesses a select list, tags, file or GPS location, so pick those yourself.

When it's done, Import Complete shows how many items were added and how many were skipped. In our example the Greek Salad row was skipped because the Recipe Box already had it.

Photos and files in a CSV

For photo, video, audio or file columns, put just the file name in the cell (e.g. risotto.jpg). For a gallery, separate several names with |. After you pick the CSV, Locate Media Files asks where those files are: a folder on your phone, a web address they can be downloaded from, or nowhere (text only).

Download a CSV template

In the same CSV sheet, Download CSV Template saves a spreadsheet with the library's columns. It contains every existing item, or just the headings if the library is empty. Fill it in on a computer and import it back. It's also a handy way to get your data into a spreadsheet.

Scan a QR code

If someone gives you a ListHive QR code, tap the QR icon at the top of the My Lists tab and point your camera at it. ListHive downloads the file and offers to import it, just like opening a .listhive file. The first time, you'll be asked to allow the camera.

Create a QR code

To share a file with many people (a class, a club, a family), upload the .listhive file somewhere online, such as Google Drive or Dropbox, and turn its share link into a QR code:

  1. Export the list or library as a file and upload it. Make sure the link is set so anyone with the link can view.
  2. Go to Settings → Create QR Code and Paste Link.
  3. Tap Test Link to check that ListHive can download it.
  4. Tap Share QR Code to send or print the picture.

Anyone with the QR code can download the file. Don't use it for anything private.
