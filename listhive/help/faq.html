FAQ & troubleshooting

Quick answers to the questions people ask most. Can't find yours? Email apptools.tvl@gmail.com and include your app version (Settings → ABOUT).

Getting started

What's the difference between a library and a list?

A list collects everything for one purpose, such as this week's dinners or a party plan: notes, headings, photos, links, files, voice notes, scanned text and more. A library is an optional place to keep things you reuse, such as every recipe you know, so you can add them to many lists and edit them in one place. See The two ideas behind ListHive.

Do I need a library before I can make a list?

No. Create a list and add notes, photos, links, files, audio notes or scanned text straight into it, or share things in from other apps. Libraries are only worth setting up for things you'll use again and again. See All the ways to add to a list.

Do I need an account? Is my data in the cloud?

No account is needed, and nothing is uploaded. Everything stays on your phone, so backups are important.

What are the [Sample] lists on a new install?

Examples to show what's possible. Delete them one by one, or all at once with Settings → Clear Sample Data.

Should I use a Simple list or a list with groups?

Simple for a one-off (a party, a trip). Groups when the list repeats or has natural parts (weeks, classes, gigs). You can change later. See Simple lists and lists with groups.

Libraries and items

Why can't I choose this type for the primary field?

The primary field names each item and must be unique, so only text, number, date, url, email, phone and GPS location are allowed. See The primary field.

I removed a value from a select list. What happened to items that used it?

Nothing. They keep the old value, marked no longer an option, until you change it.

If I delete a library item, what happens to my lists?

It's removed from every list it was in. To take it out of just one list, long-press it in that list and choose Remove from group instead.

I changed a value in a list but the library still shows the old one.

That's by design: a change made in the player is a local override for that list only (marked with ●). Open it again and tap Sync to Library to update the library too. See Changing a value just for this list.

Import, export and sharing

My CSV import says the primary field column is missing.

One column heading must match the library's primary field name, e.g. Recipe for the Recipe Box (capitals don't matter). Check the first row is headings, not data. Download CSV Template gives you a file with the right headings.

Some CSV rows were skipped.

Rows are skipped when their primary value is empty, or when an item with that name already exists and Skip Item is selected. Choose Replace to update existing items instead.

Importing a file from Google Drive or WhatsApp fails.

Save the file to your phone first (Download), then import it from Settings → Import. Also check you have free space of about twice the file's size.

I imported a list but the ticks and progress are gone.

Progress isn't included in .listhive files, so every item arrives un-ticked. A backup keeps progress.

Why does my shared text not include the photos?

Share as Text sends words only. Use Share Media Files for the photos, or Export as File to send everything to another ListHive user.

A link shows no preview picture.

Some websites don't provide a preview picture, or refuse to send it to apps. The link itself still works. Tap it to open the page.

Backups and your phone

I uninstalled ListHive. Can I get my data back?

Only if you saved a backup outside the app (Drive, Files, email, computer). Backups kept only inside ListHive are deleted with it. Install ListHive again and use Pick from device to restore. See Restore a backup.

I forgot my backup password.

Sorry, it can't be recovered, and encrypted backups can't be opened without it. Set a new password for future backups.

I forgot my app lock PIN.

If fingerprint or face unlock is on, use that to get in, then Change PIN. Otherwise the lock can only be removed by clearing ListHive's data in Android settings, which erases everything in the app. Then restore your latest backup.

How do I move ListHive to a new phone?

Back up, share the backup to Drive, install ListHive on the new phone and restore it. Full steps: Moving to a new phone.

ListHive is using a lot of storage.

Photos and videos take the most space. Check Settings → MEDIA STORAGE, run Clean Up Unused Files, and lower Backups to Keep in Auto-Backup.

Scanning and audio

Scan Text says the language pack is still downloading.

The first scan for each script downloads it. Stay online, wait a minute and tap Rescan.

Live transcription isn't offered when I record.

Live transcription needs Android 13 or later and speech recognition for your chosen language. On older phones ListHive can transcribe the recording after you stop.

The QR code scanner says “Not a ListHive file”.

The link must lead straight to a .listhive file that anyone can download. For Google Drive, set sharing to Anyone with the link. You can check a link with Test Link on the Create QR Code screen.

Ads and purchases

I paid to remove ads but they're back.

This can happen after reinstalling or on a new phone. Go to Settings → Restore Purchase, making sure you're signed in to the same Google account you bought with.

What does ListHive do with my data?

Your lists and libraries never leave your phone unless you share or export them yourself. The ad banner is provided by Google AdMob. See the privacy policy for details.

Still stuck?

Email apptools.tvl@gmail.com with your app version, your phone model and what you were doing. A screenshot helps, but please don't send anything private.
