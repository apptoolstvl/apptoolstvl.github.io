Field types

Every field in a library has a type. The type decides how you enter the value and how ListHive shows it. There are 16 types. Between them, the Recipe Box and Kitchen Suppliers libraries use all of them.

Things worth knowing

  • Choosing between select list and tags. Use a select_list when every item has exactly one answer from a short, fixed set (Cuisine, Difficulty, Status). Use multi_select when an item can have several labels and you want to invent new ones as you go (Tags).
  • Which types can be the primary field? Only text, number, date, url, email, phone and gps_location. See The primary field.
  • Empty fields. A field with no value is hidden when you view a library item. When you play a list, empty fields show Long press to add so you can fill them in on the spot.
  • Copying. Double-tap any value to copy it to the clipboard.
  • Changing a field's type later is allowed, but values already saved stay as they were typed. For example, text like “about 20” won't become a number.
  • Photos, videos, audio and files are copied into ListHive, so they keep working even if you delete the original from your gallery. They are included in backups and can go with exported files.
